
# Analisador de Corridas — Python

Projeto pessoal desenvolvido durante meus estudos de
Python pelo Curso em Vídeo.

## Objetivo

Ajudar motoristas de aplicativo a avaliar se uma
corrida atende à sua meta financeira por quilômetro,
considerando o gasto estimado com combustível.

## Funcionalidades

- Calcula a distância total da corrida.
- Estima os litros de combustível consumidos.
- Calcula o custo de combustível.
- Calcula o saldo após combustível por quilômetro.
- Compara o resultado com a meta informada.

## Tecnologias

- Python 3
- Variáveis e operações matemáticas
- Entrada de dados com input()
- Estruturas condicionais if e else

## Como executar

1. Tenha Python 3 instalado.
2. Execute: python analisador_corridas.py
3. Informe os dados solicitados.

## Limitações

O cálculo considera apenas o combustível.
Não inclui manutenção, impostos, pedágios
ou outros custos operacionais.

Nesta versão, devem ser informados números
válidos e consumo e distância maiores que zero.
